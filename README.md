## 同样是东京机房，线路差在哪

机房位置只决定了物理距离。真正影响"国内打开快不快"的，是数据包从东京回程时走哪条路。

- **国际线路（Tier 1）**：走 NTT、Lumen 这类 Tier 1 运营商，是国内运营商和日本之间最常见的公共互联路径。平时能用，晚高峰容易绕路、丢包。价格最便宜。
- **CN2 GIA（Premium）**：中国电信的顶级国际承载网，回程走这条线，稳定性和延迟表现明显更好，代价是单价高。
- **CMI / CMIN2**：中国移动侧的国际出口，对移动宽带用户更友好。

DMIT 东京的定位就是把第二、第三种线路做扎实，然后按线路分产品线卖。这也解释了为什么同一个机房的 1 核 1G 机器，价格能从月付 6.9 美元跳到 21.9 美元。

判断自己该买哪条线，最简单的办法是先看你的本地运营商和访客构成。访客主要在大陆、且能接受这个价差，直接看 Pro；如果你的业务面向日本本地或东南亚用户，或者只是要一个日本落地节点做中转，T1 就够了。

## 按场景选：三种情况，三种答案

**场景一：访客主要在大陆，网站或业务对打开速度有要求。**

从 Pro.TINY 月付入手，跑一个计费周期。月中对比一下晚高峰的延迟和丢包，再决定要不要按年锁定。不要一上来买年付大套餐。

**缺货是常态。** 东京 Pro 尤其如此，补货往往来自一批释放出来的可用 IP，卖完就得等下一次。看好了别拖太久，但也不用为了抢货去买用不上的高配。

## 常见问题

**东京 Pro 和香港 Pro 选哪个？**
看你的用户在哪。香港物理距离更近、延迟更低，但价格贵出将近一倍，而且更低价的档位经常售空。如果你的访客集中在华南，香港划算；如果覆盖全国、或者预算敏感，东京 Pro 是更平衡的选择。

**T1 能不能当国内访问主力？**
不建议。T1 走的是国际公共路由，电信和联通双程都走 NTT，部分时段还会绕道美国，晚高峰体验波动大。它适合落地和海外业务，不适合作为面向大陆的门面。

**流量用完了会怎样？**
Pro 系列暂停服务，需要等到下个计费周期恢复；T1 系列降速继续运行，按档位分别限制在 50Mbps 到 1Gbps 之间。

**能不能按月付款试试？**
可以，Pro 和 T1 的多数机型都提供月付。月付的缺点是享受不到季付、年付的循环折扣，但如果你还在评估线路，多花的这点钱换来的确定性是值得的。

**支持哪些支付方式？**
支付宝、PayPal 等主流渠道，结算页会列出当前可用的选项。
